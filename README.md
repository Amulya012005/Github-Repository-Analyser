# GitHub Repository Analyzer

# Overview
A web application built using Flask and the GitHub REST API that allows users to search for any public GitHub profile and view useful repository statistics in a clean and responsive interface.

# Features
- Search any public GitHub username
- View profile picture, name, and bio
- Display followers, following, and public repositories
- Calculate total stars across repositories
- Show the most used programming language
- Display the most starred repository
- List the latest five repositories
- Handle invalid usernames gracefully

# Technologies Used
- Python
- Flask
- HTML
- CSS
- GitHub REST API
- Requests
